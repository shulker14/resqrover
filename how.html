Rover combines person detection, browser-facing demonstrations, and a constrained conversation layer to show how a rescue-oriented robot can gather information before a human responder enters a difficult environment.

01 / Vision

Person detection

A camera frame is analyzed with a person-detection model. The dashboard demo runs locally in the browser and draws boxes around detected people.

02 / Context

Rover state

Location, patrol assignment, and future sensor data create the context in which Rover decides what capability should be active.

03 / Conversation

Short, bounded assistance

The conversation interface is designed to ask useful follow-up questions and keep the role narrow. It is a project demonstration and does not replace emergency services or medical professionals.
